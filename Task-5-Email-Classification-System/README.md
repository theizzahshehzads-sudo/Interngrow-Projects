# 📧 AI Email Classification System

An end-to-end AI project that classifies emails as **Spam** or **Ham (legitimate)** using classic
machine learning, trained and evaluated in Google Colab, and served through an authenticated,
interactive Streamlit dashboard.

---

## 1. Project Overview

| Requirement | Implementation |
|---|---|
| AI Model Integration | Naive Bayes, Logistic Regression, Linear SVM (best model auto-selected by F1-score) |
| Data Preprocessing | Lowercasing, URL/number/punctuation removal, tokenization, stopword removal, lemmatization, TF-IDF |
| Model Training / API-Based AI | Local training in Colab (primary) + optional Hugging Face Inference API path |
| User Authentication | Login screen in `app.py` (demo credentials, swappable for OAuth/SSO) |
| Interactive Dashboard | 4-page Streamlit app: Single Prediction, Batch Prediction, Model Performance, About |
| Prediction & Decision Output | Label (spam/ham) + confidence score + top contributing terms |
| Performance Evaluation | Accuracy, Precision, Recall, F1-score, Confusion Matrix, ROC curve |
| Error Handling | try/except at every stage: data loading, cleaning, training, prediction, file upload |
| Professional Documentation | This README + in-notebook markdown + docstrings |
| Deployment | Streamlit Community Cloud, Hugging Face Spaces, Render, or Azure |

## 4. How to Run (Google Colab)

1. Upload `AI_Email_Classification_System.ipynb` to Google Colab (or open it directly from Drive/GitHub).
2. **Runtime → Run all.** The notebook will:
   - Install dependencies
   - Download the dataset (with an automatic offline fallback dataset if the download fails)
   - Clean and vectorize the text
   - Train and compare 3 models
   - Evaluate performance and plot charts
   - Save `model.pkl`, `vectorizer.pkl`, `metrics.json`
   - Generate `app.py` and `requirements.txt` via `%%writefile`
3. Download the generated files (a cell at the end does this automatically), or find them in the Colab file browser under `/content/`.

## 5. How to Run the Dashboard Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Make sure `model.pkl`, `vectorizer.pkl`, and `metrics.json` are in the same folder as `app.py`.

**Demo login credentials:**
- `admin` / `admin123`
- `user` / `user123`

## 6. Deployment Guide

### A) Streamlit Community Cloud
1. Push this folder to a public (or connected private) GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select the repo/branch and set the main file to `app.py`.
4. Click **Deploy**. Streamlit installs `requirements.txt` automatically.

### B) Hugging Face Spaces
1. Create a new **Space** → SDK: **Streamlit**.
2. Upload `app.py`, `requirements.txt`, `model.pkl`, `vectorizer.pkl`, `metrics.json`.
3. The Space builds and launches the app automatically at `https://huggingface.co/spaces/<you>/<space-name>`.

### C) Render
1. Push the project to GitHub.
2. Render dashboard → **New → Web Service** → connect the repo.
3. Build command: `pip install -r requirements.txt`
4. Start command: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`
5. Deploy.

### D) Azure (App Service)
1. Push the project to GitHub (or a local Git repo).
2. Create a Python App Service via the Azure Portal or CLI:
   ```bash
   az webapp up --runtime "PYTHON:3.10" --name <your-app-name>
   ```
3. In the App Service **Configuration → General settings**, set the startup command:
   ```bash
   streamlit run app.py --server.port 8000 --server.address 0.0.0.0
   ```
4. Set up continuous deployment from your GitHub repo, or redeploy with `az webapp up` after changes.
